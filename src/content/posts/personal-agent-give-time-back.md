关于最近大热的 Personal Agent，聊聊我的一些认知。

Agent 对人的 build 能力要求目前还是比较高的。不同的人使用，效果方差很大。（当然，能力要求会随着模型的进步而逐渐降低）

真正值得担心的，不是 Agent 够不够强，而是需求是不是真实存在。

技术大体提供两种价值：生产与消费。

企业需要效率，效率是企业的生死线。更快、更好、更便宜，目标函数清晰，对人的评价体系也相对收敛。

个人不是这样。

个人真正需要的，往往不是效率，而是休息、娱乐和关系。

生活是丰富而多样的，很多事情本身就不适合被评价，也很难做 evaluation。

效率工具越先进，也未必越能让人轻松。

因为杠杆率越高，人越难抵抗杠杆的诱惑，最后往往不是减少投入，而是进一步加大投入。

工业时代，人类才有了三班倒。

农业时代反而是日出而作，日暮而息。

生产效率提高，并不天然意味着人会拥有更多时间。

所以，如果 Personal Agent 最终需要每个人都持续对着它讲话，告诉它要做什么、怎么做，我觉得这个模式大概率还是错的。

企业也不需要人人都学会使用 Agent。

就像工厂里，并不需要每个人都会操作总控系统。

卖 Agent 这件事，确实很像当年卖电脑。

虽然 PC 是 Personal Computer 的缩写，但电脑市场中，大约 60% 的需求其实来自企业。如果再考虑 BYOD，以及很多小企业通过消费渠道采购办公设备，企业使用所占的比例只会更高。

Personal Agent 想在企业里承担类似 PC 的角色，反而可能更困难。

BYOD 时代，个人资料和企业资料混杂，信息安全问题已然显现。

到了 Agent 时代，这个问题只会更加严重。

因为 Agent 不只是保存信息，它还依赖上下文。

一旦个人上下文和企业上下文混在一起，问题就不再只是数据是否泄露，还包括上下文污染、权限边界、错误调用，以及判断依据本身变得不可控。

那真正卖给个人用户的电脑是什么？

是手机。

从 IBM PC 到 Palm、Treo，再到智能手机真正成熟，中间大约隔了二十年。

顺便一提，IBM 是 International Business Machines。

当然，历史规律不能照搬。

Enterprise Agent 和 Personal Agent 的发展，也许会比 PC 和手机更加折叠。Personal Agent 未必会晚很多年。

但它大概率需要变得更不一样。

不是更“小”，也不是更“便宜”，不是让每个人拥有更高的杠杆，然后做更多的事。

而是真正把时间还给人类。
